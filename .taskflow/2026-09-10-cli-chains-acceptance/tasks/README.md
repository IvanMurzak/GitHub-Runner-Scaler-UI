# CLI chains acceptance tasks

Tasks are immutable implementation contracts. Progress, run identifiers, pull
requests, and completion state live only in the parent `ROADMAP.md`.

Groups are conflict domains. A owns the published-command accountability test;
B owns the black-box local chain modules and runs sequentially; C owns the WSL
acceptance module; D owns final cross-track gates and documentation. Groups A,
B, and C may execute concurrently until D joins their evidence.
