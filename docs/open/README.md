# Open items

Things this project is waiting on, where waiting is the only way to know.

A note belongs here when it cannot be settled by a test or a review — when the
answer arrives days later, on a real host, or not at all. Each one says what to
look at, when, and what it means either way, so that whoever reads it next does
not have to reconstruct the investigation that produced it.

Delete a note once its question is answered. A stale note here is worse than no
note: it sends somebody looking for a problem that is gone.

Not for bugs with a known fix — those are issues or pull requests. Not for
finished investigations — those are `docs/spikes/`.
